# data_visualization_training
This is my repository for the Anudip data vizualization training.

## 🚀 Retro File Explorer

This repository comes with a built-in, beautifully designed retro file explorer to easily navigate and preview the files. It requires **zero dependencies** to install. 

### How to use it:

1. Clone or download this repository.
2. Open your terminal or command prompt inside the project folder.
3. Run the following command:
   ```bash
   python start_explorer.py
   ```
4. A retro-themed window will automatically open in your default web browser where you can navigate through the folders and double-click to view files!
